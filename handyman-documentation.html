Handyman Services Website - Project Documentation

Project Overview

This document outlines the complete development plan for a Handyman Services website built with CodeIgniter 4.6. The platform will serve as a single-vendor system with separate admin and user panels, featuring an easy-to-use service booking system, advanced marketing tools, and a modern responsive design.

CodeIgniter 4.6
MySQL
Bootstrap 5
JavaScript/jQuery
AJAX
RESTful API

System Architecture

The application follows the MVC architecture pattern of CodeIgniter 4.6 with additional service layers for business logic and repositories for data access.

Key Components:
  • Client Browser - User interface for customers and admin
  • CodeIgniter 4.6 Application - Core application framework
  • Admin Panel - Management interface for the service provider
  • User Panel - Customer-facing interface for booking services
  • Database (MySQL) - Data storage
  • Email Service - For notifications and marketing
  • Payment Gateway - For processing payments
  • Marketing Tools - For promotions and customer engagement

Database Design

The database schema includes the following key tables:

Table Description Key Fields
users Stores user information for both customers and admin id, email, password, name, phone, address, role_id
roles Defines user roles and permissions id, name, permissions
services Contains all available handyman services id, name, description, price, image, category_id, is_active
categories Service categories for organization id, name, description, icon
bookings Service booking records id, user_id, service_id, booking_date, status, notes, total_amount
reviews Customer reviews for completed services id, user_id, booking_id, rating, comment
payments Payment transaction records id, booking_id, amount, payment_method, transaction_id, status
marketing_campaigns Marketing campaign details id, name, description, start_date, end_date, status
coupons Discount coupon information id, code, discount, valid_until, campaign_id, usage_limit, used_count
affiliates Affiliate partner information id, user_id, code, commission_rate, status, payout_method
affiliate_transactions Records of affiliate-generated bookings and commissions id, affiliate_id, booking_id, commission_amount, status, date

Technical Implementation

CodeIgniter 4.6 Best Practices
  • MVC architecture with proper separation of concerns
  • Use of Services layer for business logic
  • Repositories for data access
  • Filters for request/response handling
  • Events for system-wide notifications
Security Measures
  • CSRF protection
  • Input validation and sanitization
  • Output escaping
  • Proper authentication and authorization
  • Password hashing with bcrypt
  • Rate limiting for sensitive endpoints
  • SQL injection prevention
Database Implementation
  • Migrations for database versioning

Frontend Implementation

  • AJAX for dynamic content loading
